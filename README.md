# Stop Motion Creator

A minimalist, light-themed stop-motion animation studio web application. Draw frame-by-frame animations, adjust FPS, preview in real time, and export directly as video.

## Features

- **Smooth Hand Drawing**: Brush & Eraser tools with adjustable stroke width and color picker.
- **Onion Skinning**: Semi-transparent preview of previous frame for tracing movement.
- **Custom FPS**: Variable frame rate control from 1 to 30 FPS.
- **Timeline Reel**: Visual filmstrip of all frames with add, duplicate, delete, and reorder.
- **Real-Time Playback**: In-canvas loop preview.
- **Video Export**: Export animations directly to `.webm` / `.mp4` video with preview player.
- **Preloaded Demo**: Included bouncing ball demo.

## Shortcuts

- `Space`: Play / Pause
- `→` / `←`: Next / Previous frame
- `N`: Add blank frame
- `D`: Duplicate current frame
- `P`: Pen tool
- `E`: Eraser tool
- `O`: Toggle Onion Skin
- `Ctrl + Z` / `Ctrl + Y`: Undo / Redo
